## 图3: 因果感知跨模态融合机制详细示意图

```
步骤1: 因果图学习 (Causal Graph Learning)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

         ┌──────────┐
         │  文本模态  │
         │ (M_text) │
         └─────┬────┘
               │ τ₁₂ = 0-1天
               ↓
         ┌──────────┐
         │  数值模态  │
         │ (M_num)  │
         └─────┬────┘
               │ τ₂₃ = 1-3天
               ↓
         ┌──────────┐
         │  图像模态  │
         │ (M_img)  │
         └──────────┘

因果关系识别:
• 基于结构方程模型 (SEM)
• 最小化预测误差 + 最大化稀疏性
• 融入领域知识约束 (价格不能先于新闻)


步骤2: 时滞参数建模 (Time-lag Modeling)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

时间轴: t-3    t-2    t-1     t     t+1
        ─────┼─────┼─────┼─────┼─────►

M_text:               ████
                       ↓ τ=0-1天
M_num:                     ████
                            ↓ τ=1-3天
M_img:                          ████

因果时滞矩阵 τ:
        │ Text  Num   Img
    ────┼────────────────
    Text│  0    τ₁₂   τ₁₃
    Num │  ∅     0    τ₂₃
    Img │  ∅     ∅     0

(∅ 表示无因果关系或反向因果被约束)


步骤3: 因果约束注意力计算 (Causal-Constrained Attention)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

对于模态 j 在时间 t:

        Q_j^t (Query at time t)
           │
           ├──────────────┐
           │              │
  只关注 t-τ_{ij} 及之前   │ 屏蔽未来信息
           │              │
           ▼              ▼
    K_i^{t-τ}, V_i^{t-τ}  ✗ K_i^{t+1}

数学表达:
┌─────────────────────────────────────────────────────────┐
│ Attention(Q_j^t, K_i^{t-τ}, V_i^{t-τ})                 │
│                                                         │
│ = softmax(Q_j^t · (K_i^{t-τ})^T / √d) · V_i^{t-τ}    │
└─────────────────────────────────────────────────────────┘

具体案例: 预测 t 时刻的趋势
┌──────────────────────────────────────────────┐
│ H_num^t  关注:                                │
│   • H_text^{t-1}, H_text^{t}  (τ=0-1)      │
│   • H_num^{t-5:t-1}  (历史数据)             │
│                                              │
│ H_img^t  关注:                                │
│   • H_text^{t-3:t}  (τ=0-3)                │
│   • H_num^{t-3:t-1}  (τ=1-3)               │
└──────────────────────────────────────────────┘

优势: 沿正确因果路径整合信息, 避免虚假关联
```
